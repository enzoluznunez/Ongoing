3D chart design

A stand-in card for the chart column, and three 3D chart kinds built on one chart card folded into a corner, with a 16 curve wherever two sides meet. Drag the chart to turn it; nothing else on it moves. The controls change every drawing on this page.

Chart column stand-in

A 3D chart can't be drawn as a flat preview, so its slot gets a blank card the size of a 2D preview (360.5 × 240.5, radius 16) saying Cannot display at 16 / 600, the same as the Documents column's blank page. The 2D card above it is there for scale. Press the stand-in: it pins the 3D chart and takes the black outline.

Three fixed views, each one its own drawing

Each view looks straight at one side, with no perspective, at one shared scale so sizes compare directly. Labels are printed on the card, so a side seen edge-on takes its labels with it.

To decide before code

  • Axis ranges. Every number axis uses the 2D rule: 5 ticks on steps of 1, 2, 2.5 or 5. That can leave room: staff hours run from 2k to 10k for shops between 3.9k and 7.6k.
  • Drop lines and shadows. New for the scatter, with nothing like them in 2D. Each dot gets a line down to the floor and a soft shadow there, so you can read where it sits on the floor grid.
  • Surface colour. The surface uses the 2D heatmap ramp, which repeats its height. A single colour with shading alone is the other option.
  • Break-even line. A black line, 2 wide, where profit is 0. It's the one annotation drawn on a mark; 2D charts have none yet.
  • Surface data. No sample PDF has a what-if table yet. One would need adding, with a caption the planner can read, such as "Shown best as a surface".
  • Title around the corner. Centred on both walls' combined width, curve included, so it leans toward the longer wall. Straight on, only the part on the wall you face can be read.
  • Value axis twice. Each wall carries the vertical axis on its outward edge, so the back wall's sits on the right. One could be dropped.
  • Edge-on labels. In the straight front and side views the floor's labels disappear. Facing you, every label can be read.
  • Card shading. A fixed light, turning with the chart, shades the card so the curves show. At 0 the card is pure white and the curves disappear.
